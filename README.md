# Стенограф — фотодневник ремонта

PWA-приложение для фиксации стадий ремонта: фотографируете каждую стену (и потолок, и пол) на каждом этапе и сравниваете «до/после» слайдером-шторкой.

**Живая версия:** https://vvana.github.io/stenograf/ (открыть на телефоне → «Добавить на главный экран»)

## Возможности

- **Несколько объектов** — квартиры/дома, у каждого свои схема, этапы и фото.
- **Схема квартиры со встроенным редактором** — комнаты добавляются и растягиваются пальцем (снап к сетке 10 см). У каждой комнаты 6 кликабельных поверхностей: 4 стены + потолок + пол. В маленьких комнатах плашки «Потолок»/«Пол» автоматически сжимаются до значков ⬆/⬇.
- **Фотоистория поверхности** — тап по стене на схеме → фото по этапам, съёмка прямо с камеры (сжатие до 1600 px JPEG). Бейджи на схеме показывают число фото.
- **Слайдер «до/после»** — сравнение двух любых этапов шторкой; при нескольких фото на этапе можно выбрать конкретное.
- **Этапы** — настраиваемый список (демонтаж → … → готово), статусы «не начато / в работе / готово», переименование, свой порядок.
- **Разметка фото** — калибровка (4 угла стены или рулетка в кадре), размеры в сантиметрах, заметки, наброски, точки для мастеров (розетки, выключатели, вода…) со статусом «сделано» и автором. Отчёт «Задание для мастеров» с фильтром по специальности, печать в PDF.
- **Команда без сервера** — «Отправить схему коллегам» (килобайты), «Отправить объект с фото», импорт со слиянием без дублей: рабочие снимают на любых телефонах, прораб собирает всё обратно.
- **Быстрое создание схемы** — подложка из плана БТИ с масштабом по двум точкам и обводкой тапами, мастер «по обмеру» (длина → угол), комнаты любой формы до 10 углов.
- **3D-тур** — «кукольный домик» квартиры из схемы и фото: на стенах последние снимки (откалиброванные выпрямляются по перспективе), переключение этапов, режим «внутри комнаты», панорамы 360° (снимаются штатной камерой в режиме «Панорама»), переходы по мини-плану, зеркала отражают комнату по-настоящему (Reflector), двери и окна видны как проёмы. Работает офлайн (three.js в `vendor/`).
- **Калькулятор** — площади стен (за вычетом проёмов), пола, потолка и ориентировочный расход материалов.
- **Резервная копия** — весь архив (схемы, этапы, фото) в один JSON-файл; импорт на другом устройстве.
- **Офлайн** — service worker, все данные только в IndexedDB на устройстве, на сервер ничего не отправляется.

## Технологии

Vanilla JS + IndexedDB, без сборки и зависимостей. Файлы:

| Файл | Что это |
|---|---|
| `index.html` | оболочка |
| `app.js` | вся логика: роутер, экраны, редактор схемы (SVG), слайдер, бэкап |
| `db.js` | обёртка над IndexedDB (projects / rooms / stages / photos) |
| `app.css` | стили, mobile-first, тёмная тема через `prefers-color-scheme` |
| `sw.js` | service worker, network-first с ревалидацией HTTP-кеша |
| `manifest.webmanifest` | PWA-манифест |
| `tour.js` | 3D-тур и панорамы (three.js) |
| `vendor/` | three.js r170 (ES-модуль, подключён через `<script type=module>` в `index.html`) |
| `icons/` | альтернативные варианты иконки |

## Запуск локально

Любой статический сервер, например:

```bash
python -m http.server 8787 --directory .
```

Открыть http://localhost:8787. Для PWA-функций (установка, офлайн) нужен HTTPS или localhost.

## Нативная iOS-версия (лидар)

Папка `native/` — обёртка Capacitor и Swift-плагин `stenograf-roomplan` (Apple RoomPlan): «📡 Обмер лидаром» в редакторе схемы (комната строится из скана, двери/окна становятся проёмами, id стен и фото сохраняются при переобмере) и «🚶 Обход этапа» на схеме (кадры стен снимаются сами при обходе и ложатся на стены уже откалиброванными). Нужен iPhone Pro (12 Pro и новее) с iOS 17+.

**Сборка без Mac** — GitHub Actions (`.github/workflows/ios.yml`, macOS-раннер) собирает неподписанный `Stenograf-unsigned.ipa` при каждом пуше в `main` (или вручную: Actions → iOS build → Run workflow). Артефакт лежит в результатах запуска.

**Установка на свой iPhone без платного аккаунта** — [Sideloadly](https://sideloadly.io) на Windows:
1. Установить Sideloadly и iTunes/Apple Devices (драйверы USB), подключить iPhone кабелем.
2. Перетащить `.ipa` в Sideloadly, войти своим Apple ID (бесплатный), нажать Start.
3. На iPhone: Настройки → Основные → VPN и управление устройством → доверить профиль.
4. Подпись живёт 7 дней; Sideloadly умеет обновлять её автоматически по Wi-Fi.

Данные PWA переносятся в нативную версию через «Резервная копия» → «Импорт».

## Деплой

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root. Обновление — просто `git push`, клиенты подтянут новую версию при следующем открытии (SW network-first).
